# 当前项目材料

此目录同步桌面项目中的当前申报草稿、研究计划、依据整理、工程说明和试验图文，来源与文件校验值见 manifest.json。工程源码与启动入口位于仓库根目录；最新界面与接入行为以根目录 docs 和源码为准。研究材料中的计划、阶段实测与未来工作应分别理解，不能将计划视为已完成成果。

原始视频、弹幕与含逐条真实弹幕的交互报告、模型权重、登录凭据、个人本地配置和运行缓存未上传。第三方论文全文、模型卡镜像和 FrameScope 源码副本未重复发布，保留来源清单与接入说明供追溯。部分材料引用桌面本地路径或上述未上传文件，完整原始复现仍需本地材料；本仓库不冒称包含这些数据。

此目录由当前桌面成果复制，后续修改后需要重新同步。试验报告记录此前已验证的本地100条闭环；最新远程 API 全链路状态及连接开放规则见 ../docs/model-access.md。
