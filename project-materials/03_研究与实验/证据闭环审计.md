# 证据闭环审计

## 当前判断

已有“为什么做、参考什么、计划怎么测”的体系；尚没有“真实数据上做到了什么”的实测证据。E01–E44是来源，不是44项已通过验证。T01–T25是技术实现候选，不是25个本项目已跑通模块。本审计按2026-09-11当前材料判断，完成一项需补对应验收记录再更新状态。

完整证据链应为：教师具体任务 → 需要观察的表达 → 标签操作定义 → 人工参照 → 模型输出 → 聚合与解释 → 教师行动 → 使用效果。输入许可与复现记录贯穿全链。

## 缺口与补证方法

P0指立项前真实闭环需要解决或明确排除的事项；P1指后续正式研究重点。边界固定项不是“等待一个更强模型”的问题。

## 研究问题与总设计对应

RQ4（问题保留）：在中文录播课程中，问题单元拆分和逐阶段审计能否比直接摘要更好保留隐含、笼统和单次问题，且不显著增加虚构问题？

RQ1（模态消歧）：对指代/对象不清的反馈，选择性加入转录和画面能否改善解释；收益是否超过由对变错、耗时和费用？

RQ2（归属与拒判）：时间与语义联合方法能否比固定窗更好地定位知识点，并识别无法可靠归属的反馈？

RQ3：教师在相同原始材料权限下，能否更快找到依据成立的改进或保留行动，同时避免增加错误采纳？

六类分类是研究基础设施，RQ1–RQ4是可被实验反驳的研究问题。问题编号沿用总体设计；三条贡献线索对应问题留存、模态与归属、教师行动。模型换代应作为受控配置，不能每次测试都换模型再汇总成一个成绩。

## 最小证据包

立项前保留：一条真实授权课程的输入登记、模型运行清单、端到端报告、全量ID校验结果、人工抽核表、已知错误示例和复核保存记录。另用未调参的短片段复跑，避免只呈现演示材料上修好的结果。全部真实失败如实列出。

标注起步可选覆盖正负、边界、低频和多问的100–200条进行规范校准；这是工作量起步建议，不是统计学充分样本。至少一部分连续片段不按模型结果筛选。规范修改后旧试标只作开发材料，正式冻结测试不用于改提示。

论文需要更强证据包：独立视频/作者划分、预先冻结指标与基线、模态对照、教师任务实验、误差及成本分析。国家级竞争力来自研究问题清楚、证据可信和团队能解释复现，不能以大模型规模、论文专利承诺替代。

## 关键原始依据入口

- [E21 测量标准](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)：用途与解释必须有相应证据。

- [E27 标注一致性](https://aclanthology.org/J08-4004.pdf)：一致性指标不等于正确性。
- [E28 CheckList](https://aclanthology.org/2020.acl-main.442/)：按能力组织错误测试。
- [E29 ALCE](https://aclanthology.org/2023.emnlp-main.398/)：引用支持需要独立检查。
- [E36 仪表盘设计与评价](https://link.springer.com/article/10.1186/s41239-023-00394-6)：教师参与及实际使用评价。
- [E37 教师数据使用综述](https://link.springer.com/article/10.1007/s11423-024-10356-y)：数据到行动及结果评价的过程参照。
- [E38 教师生成式AI应用指引](https://jyt.hlj.gov.cn/jyt/c110476/202512/c00_31893033.shtml)：课堂实录支持教学反思，不认证本系统效果。
