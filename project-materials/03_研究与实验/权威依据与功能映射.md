以下为本项目制定的操作定义，不冒充任何文献给出的现成量规。外部文献支撑概念或方法，最后一列必须用本项目证据补足。

| 主张/报告位置 | 证据基础 | 操作定义与输出 | 需要验证/禁止推断 |
|---|---|---|---|
| F01 全课时长、知识点、弹幕数量 | 数据登记；E34；结构参照E12 | 时长来自媒体；知识点按确认粒度去重；N_raw/N_valid/N_teach分开 | 校验漏片与章节误分；不能把自动章节数说成客观唯一知识点数 |
| F02 教学评价：肯定/批评/混合 | E39、E41，E06 | 按评价对象及倾向拆分，首页正负并列，点击全部依据 | 对象抽取和极性分别验；肯定不是掌握，自身焦虑不是教师批评 |
| F03 理解状态自述 | E43，E21解释边界 | 自述理解、部分/不确定、未理解；按明确文本编码 | 不等于测得理解，更不是情绪类别；自发弹幕适配需试标 |
| F04 学习情绪 | E02、E40 | 教育相关情绪候选及混合/未知；与评价倾向分开 | 被感知表达不是真实心理状态；教育细类与共享任务标签区别记录 |
| F05 知识交流 | E11、E22、E03 | 回答/解释/推理/标记/总结/经验/补充/纠错，单纯提问归F07 | 正确性另核，无交互链不判协作，不算掌握 |
| F06 改进建议 | E23 | 弹幕中的请求意图＋目标变化 | 不混入模型建议；不要求同时存在不满 |
| F07 问题与求助 | E11、E22、E25 | 具体/隐含/核验/拓展问题、笼统求助和待核候选 | 过滤前检查漏检；纯情绪不虚构问题，信息需求不自动归困惑 |
| F08 全部问题可查 | E24、E30是方法参照；完整性为项目要求 | comment→question_unit→cluster→report映射，多对多；单次项保留 | 单元召回率与已识别项保留率分开；不得无测试宣称100%识别 |
| F09 问题概述 | E09、E29、E30 | 摘要按课/知识点/问题簇分层，每项有问题单元来源 | 否定、条件、少数观点遗漏与无依据新增 |
| F10 主题词云 | E26；频次定义为项目规范 | 按不同问题弹幕数；语义分组＋精确频数表＋原文 | 词云不取代清单；频率不代表人数、严重程度 |
| F11 播放位置分布 | E04、E22；计数规则 | 共同时间轴；类别n/N，密度条/分钟 | 不称同一学生变化；末窗实际时长；缺片不补零 |
| F12 片段归属 | E25、E12 | 时间候选＋转录/画面；多候选/未知显式保留 | 对比固定窗，报告误归属及拒判覆盖 |
| F13 讲解辅助解释 | E07、E12；E21推断边界 | 观察与候选原因分离；转录/画面/声音均定位 | 模态导致由对变错；不能仅凭时序关联推因果 |
| F14 单条证据展开 | E09、E29 | 引用ID有效、文本忠实、播放时间、相反反馈入口 | 引用存在性＋主张支持率；公开原文另核E15–E16 |
| F15 改进/保留行动 | E18、E36–E38 | 教师确认问题、选择行动、写验证方法；可保留原处理 | 有效发现、错误采纳、定位耗时；不以满意度替代效果 |
| F16 集中反馈提示 | E21；截图是需求来源 | 5分钟/30%仅对照；同时显示n/N与候选理由 | 误报/漏报/教师负担；无权威统一阈值的核实证据 |
| F17 多领域泛化 | E21、E25；项目实验设计 | 视频/作者隔离；高数域内与计算机域外分开 | 独立课程数与置信范围；三视频不能代表全学科 |
| F18 研究与发布可用 | E14–E16、E31–E35 | 授权/伦理/处理方台账，内部与公开用途区分 | 逐项许可及程序；政策鼓励不等于数据授权 |

## H. 证据触发的当前设计修订

1. 更新为六类入口，保留正面信息，底层多轴；不构造课程质量总分，不用异质标签的内部一致性假装量表效度（E21、E27）。
2. 新增question_unit，完整性覆盖识别、拆分、聚合、摘要和原文入口；低频与笼统问题不被过滤（E24–E25的方法适配）。
3. 词云定位主题导航，配精确频数与完整清单；语义分组作为可试验布局（E26）。
4. CoKnowledge列为核心近邻；创新转向问题保留、局部消歧和教师正确行动，不宣称首次集成（E22）。
5. 教师试验两组都有原始媒体权限；同时检验积极发现、错误采纳和误信，不只满意度（E36–E37）。
6. 人员与个人信息数据研究实施前走学校伦理适用判断及相应程序；公开服务另核生成式AI范围与标识（E31–E33）。
7. 正向发现保留同等证据标准；反馈出现与教学因果分开，通用政策不使本系统自动获得高风险评价用途（E20–E21）。

这些已写入当前设计文件，是研究方案修订；模型、真实报告与实验结果仍未实现或取得。
