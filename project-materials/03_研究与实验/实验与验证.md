# 实验与验证 

目的：验证反馈解析和教师复盘价值。下列均为实验计划，尚无实测结果。三条视频可证明流程可运行，不能支持全学科泛化、学习成效或国家级竞争力保证。

依据：E21明确用途对应验证；E27指导标注一致性；E28补能力测试；E29补引用评价；E36–E37指导教师任务与实践验证。CoKnowledge（E22）作为核心近邻，不能仅以分类、词云、时间轴证明创新。详细来源见《权威依据与功能映射》。

## 数据与切分

前期选取三条高数视频，覆盖复习速通、专题讲解、解题方法，时长约10–40分钟，每课以约一万条弹幕为选材目标，记录实际取得数量和覆盖范围。前期复用已有研究方法运行完整流程，并用300–500条人工检查发现明显错误。需要全区间分层抽样，包含低密度、无关、反讽、段落边界和内部反馈。峰值用于找问题，不能代替代表性评价集。

中期围绕三课约三万条弹幕进行全量基础标注，安排双人独立标注与分歧裁决；所有问题单元另作深入标注，包括隐含、笼统、单次及一条多问。核心数据可进行三轮留一课程测试，每轮训练和调整只使用其余课程。另预留3–6条新增高数课程作为独立测试，课程范围及抽样方案在试点后确定，测试材料与标签不用于训练、选提示或调整阈值。新增课程无需每课一万条；三个核心视频仍是全量标注的主体。测试按视频隔离，条件允许另设未见作者测试；同课剪辑、重复上传、近重复文本不得跨集合泄漏。

阶段三以 6–12 条计算机课程作探索性外部测试，保留未适配模型测试和少量适配后测试，分别报告。若授权只能取得教师自有材料，场景要如实更名，Bilibili 外部验证列未完成。

规划规模不是统计功效结论。先确定主要结果需要识别的最小有用差异或允许的不确定范围，再结合试点的课程间差异、教师间差异及重复任务相关性估计规模。样本不足时报告探索结果和区间，不将不显著写成无效，也不将便利样本推广到全部高校。

问题保留评价增加过滤前人工参照：完整连续片段逐条检查，包含被机器判作无关/纯情绪/非问题的记录。另分层抽取隐含、笼统、单次、混合、反问及一条多问；加抽难例单列，或用已知抽样概率加权，不把富集样本的平均值冒充总体表现。

## 对照与消融

“消融”是只撤去某项输入，检验它是否带来帮助。保持模型、提示预算、测试集和统计定义可比。

| 配置 | 输入/方法 | 检验的问题 |
|---|---|---|
| B0 | 关键词规则、固定窗、频次列表 | 最低成本方法能完成多少 |
| B1 | 弹幕文本模型 | NLP 相对规则的收益 |
| B2 | B1 + 局部转录 | 讲解上下文能否消歧 |
| B3 | B2 + 相关板书/课件画面 | 公式与指代是否改善，代价多大 |
| B4 | B3 + 必要声音片段特征 | 声音异常相关反馈是否更准 |

归属另外比较固定时间窗、时间候选加语义判别、带拒判机制。记录每类错误、费用、耗时。只在声音能回答问题的子任务上检验 B4，不能为“多模态”机械处理全部视频。上下文可能误导模型，需统计由对变错的案例。

问题完整性另外比较：直接摘要；聚类后摘要；问题单元拆分＋聚类＋逐阶段完整性审计。各配置使用同一原始材料与相近输出预算，不能人为只给基线高频记录。比较隐含、笼统、单次与多问单元的召回、误合并、摘要条件遗漏及人审代价。

行为测试组借鉴E28：否定翻转、同义变换、情绪词附加、一条多问、讽刺、公式条件改变、滞后指代、重复记录。用领域人员确认变换前后应保留或改变的标签，不机械假设所有改写都不变。固定5分钟/30%提示仅作为候选对照，比较误报、漏报、每课回看负担和窗口敏感性。

## 技术指标

- 标签：逐轴每类精确率（标出的有多少正确）、召回率（应找的找到多少）及宏平均 F1（平衡各类）；不能只报总体准确率掩盖少数类。
- 归属：知识点正确率、区间匹配、明确归属覆盖与误归属率；标注多候选的记录独立评价。不同区间容差做敏感性分析，事先声明。
- 聚合：抽样评论对“应合并/不应合并”的判别准确性、问题遗漏、错误合并，由独立人员核验；主题一致不等于问题相同。
- 摘要：逐条主张的证据支持率、引用定位正确率、遗漏重要问题、无根据因果/掌握结论发生数。自动引用存在性检查不等于语义忠实。
- 成本：每小时视频的人审分钟、处理耗时、模型费用及重试；不能把标注劳动隐藏为零成本自动化。

问题完整性评价中，问题单元召回率（识别是否漏）、已识别单元保留完整率（流程是否丢）、摘要信息需求覆盖率（表达是否漏）分别计算；三者不能互相代替。归属与自动解释报告覆盖—错误关系；如显示概率，另用独立数据检查校准，模型自报概率不作可信度。

六类首页专项：问题与知识交流不默认重叠；理解自述与学习情绪分别有原文依据；教学评价同时识别方面对象与肯定/批评；建议判独立意图。逐轴报告结果，同时检查“懂了→积极情绪”“焦虑→教师差评”等不合法的推导。教育情绪细类不直接套共享任务的英文基础情绪标签，中文高数需要独立标注。来源E39–E43及当前定义见分类文件。

指标按视频汇总，报告分布；有足够独立视频后按视频重采样估计不确定范围，不把同一视频的一万条相关评论当一万个独立课程样本。正式阈值由试点后预登记，当前不虚构性能目标已达成。

## 教师任务实验

招募愿意参与的教师/助教前完成风险评估，按E31与学校程序办理伦理适用判断和相应审查、同意及退出安排。先访谈确认任务，再在原型和试用阶段持续纳入教师意见；参与人数由试点差异、设计和资源估计，不把方便样本当充分统计保证。

对照为弹幕列表加基本时间/词频图；实验为带知识点归属、证据卡和复核的报告。两组均可访问相同原始弹幕、视频与转录，避免把信息权限差异误认作界面收益。同一参与者做不同但难度匹配的视频任务，平衡先后顺序，避免先看过内容造成优势；独立评审者尽可能不知道使用哪个界面。整体对照检验组合效果，若要归因某个功能，另作只改变该功能的实验。

主要结果：固定时间内发现且经专家确认的具体问题数、错误问题数、证据定位耗时、建议可实施性。次要结果：使用感受、认知负担、信任是否与实际错误相称。记录教师推翻模型的情况。

正式分析前从上述结果冻结主指标：建议技术主指标为问题单元召回率，教师主指标为固定时间内依据成立的具体发现数，同时约束错误发现/错误采纳。积极发现另设任务：找到被明确肯定的讲解方式并核对对象，不能只测找错能力。报告问题正确性、发现价值与行动可实施性各自的评审定义和分歧，AI自评不作独立参照。

统计考虑教师与视频两个层级，采用适合样本规模的配对/分层分析，报告效应和不确定范围；不能把同一人的每次点击或同课每条弹幕当作独立样本。涉及多指标比较说明探索性质或相应控制方法。

教师“愿意用”不是学生“学得更好”。若未来要研究学习成效，需要对应知识点的测验、可比较的学习者与教学条件、预先设定的分析；单纯更新视频前后弹幕变化不能排除观众组成、热度和时间变化。

## 复现与失败判据

保存取得方式、数据版本/授权编号、清洗代码、划分清单、规范、模型与提示版本、随机种子、统计脚本、错误样例和人工修订记录。模型 API 变化需要记录可复现限制。

若额外模态收益不稳定，保留成本更低的方法；若教师误信率升高，收紧结论模板和人工复核；若归属不准，退回时间窗报告；若无法取得数据，先做合成链路和合法自有材料试点，明确外部有效性尚未验证。

## 判定规则专项评价

执行[教学反馈判定细则](教学反馈判定细则与报告依据.md)中的发现级抽样与对照，单独检验正面建议依据、内容反证、局部检查误称全课缺失等错误。与直接摘要、检索后摘要对照，报告有效发现覆盖和错误拒判，防止仅靠减少输出提高支持率。
