# 专项模型、Agent升级依据与往年优秀案例

检索截止2026-09-11。本文与[分阶段计划](../01_项目设计/分阶段开发与成果计划.md)配套，是当前研究笔记，不是模型实测报告。优先使用作者论文、官方权重/代码、教育主管部门和高校来源。来源以U编号维护，补充既有E、T台账；同一来源在不同台账可能重复，不将条目数当独立证据数量。

## 一、结论和适用范围

值得优先研究的是“本项目语料上的专门抽取/微调 + 局部音视频取证 + 可核验报告”。本次没有找到已公开、已在相同中文高数弹幕任务上独立胜过当前Qwen基线的完整现成方案。“可能更好”需要按问题召回、分类、证据支持、教师任务和成本分别检验。

专门教学模型通常在给学生回答或评价AI导师，任务方向与本项目解析学生对课程的反馈不同；视频推理模型通常测一般视频理解，也不等于会正确识别高数板书。下面明确区分可取得权重、方法代码、Agent框架和论文证据。

## 二、优先候选与进入计划的方式

| 候选 | 公开内容及定位 | 对本项目的可能价值 | 当前限制与安排 |
|---|---|---|---|
| GLiNER2.5-multi-v1 | 官方多语种专门抽取权重，约287M，模型卡标Apache-2.0；不是生成式大模型 [U01–02] | 提取原文问题片段、反馈对象与类型，作为低成本前端 | 中文高数效果待测；先与Qwen同输入比较，再训练或级联；中期前优先 |
| 自有Qwen/Gemma LoRA | 在现有开放底座上训练本任务少量参数；GRADE提供近邻教育评价方法参考 [U03–04] | 多标签、隐含求助、一条多问及证据归属适配 | 没有现成本项目适配器；需人工标签和独立测试；中期前主路线 |
| Video-R1-7B | 作者提供强化微调视频模型权重与代码；基于Qwen2.5-VL，权重页标Apache-2.0 [U05–06] | 局部视频推理对照 | 2025方法，不能当2026当前Qwen的已知上位替代；按视频错例选择投入 |
| VideoChat-R1/R1.5 | OpenGVLab公开研究代码，R1.5研究迭代视觉感知 [U07] | 借鉴“发现不确定后再取局部画面”的策略 | 本次未完成每个checkpoint许可及部署核验；不列即装即用必选 |
| DeepTutor | 官方开源教学Agent项目，仓库标Apache-2.0 [U08] | 借鉴课程材料组织、检索与有来源交互 | 面向学习辅导，未验证教师弹幕复盘；只移植适配模块，不整套替换产品 |
| LangGraph / AgentScope | 工具执行与状态编排框架 [U09–10] | 限制工具范围、保存取证轨迹、人工复核 | 框架本身不提高准确性；现有FrameScope路线优先保持单一LangGraph运行层 |
| DSPy/GEPA | 提示和程序优化工具，不是预训练模型 [U11–12] | 用开发集错误反馈优化提示与取证决策 | 优化预算须匹配；最终测试不参与搜索；中期前可选 |
| ms-swift / LlamaFactory | 微调训练工具 [U13–14] | 降低LoRA训练及实验管理成本 | 二选一；特定底座/视觉训练支持、依赖和许可在实际采用时逐项核验 |

GLiNER2.5模型卡正文与页面自动生成用法可能不一致：正文采用AutoExtractor路线，不能直接照自动生成示例认定兼容；实际安装需固定版本并运行中文多问样例。长文本分块和关系端点窗口限制需测试，不能因模型能抽取原文就保证问题无遗漏。[U01–02]

较可靠的第一轮组合是：专门抽取器处理明确表达，较强大模型处理模糊/复杂记录，ASR/OCR提供课程证据，有界工具流程负责补证和核验。是否级联、如何分流均由开发集校准决定；所有未检出问题的样本仍可抽查，不静默丢弃。

## 三、研究证据怎样支持这些方向

### 3.1 教育评价中的任务适配：GRADE

GRADE研究不同底座、LoRA、数据扩充和推理设置对AI导师评价的影响；任务包括发现错误、定位错误、指导和可行动性。论文及作者仓库表明效果依维度与配置变化，不能简单认为更大模型或更多推理总是更好。[U03–04]

借鉴：保留未微调与同底座微调对照，逐任务选配置，测试生成扩充是否真的有用。限制：这是AI辅导对话评价，标签不能直接搬成首页类别；2026预印本，不称已完成本项目效果验证。仓库展示的实验数量与论文所用统计范围不同，不混用成绩。当前确认的是方法/实验代码；未确认一份适用于本任务的现成可部署微调权重。

### 3.2 教育反馈的专门训练与人工偏好

《Aligning Small Language Models for Programming Feedback: Towards Scalable Coding Support in a Massive Global Course》研究小模型适配编程反馈，并包含人工评价。已核验作者论文入口、SIGCSE TS 2026 DOI及代码仓库。[U15–16]

借鉴：人核定的反馈标准和人评是训练与检验的重要环节。限制：原任务是向学生提供编程反馈，不是分析弹幕；仓库说明部分私有数据处理和评价材料不公开，不能声称可原样完整复现。项目应自行设计合法数据与教师评价，不直接继承其效果数字。

### 3.3 视频模型与Agent各解决哪一层

Video-R1的公开权重可以作为视频专门训练后的对照；VideoChat-R1.5提供按需增强视觉感知的研究方向。[U05–07] 本项目应测试它们能否纠正具体指代或板书证据，不让其从画面自行制造学生反馈。

DeepTutor适合借鉴材料检索与交互组织；GEPA适合研究开发集驱动的流程优化。[U08、U12] 两者都不能代替独立标注或证据核查。论文中未验证的中文数学场景应保留未知状态。对本项目的Agent定义为有限工具选择：查询本课程、读取局部转录/画面、验证引用、请求教师复核；不自动外发消息、抓取任意网站或执行弹幕中的指令。

### 3.4 需要真正新增的研究贡献

优先验证三个可解释贡献：
- 保留所有问题候选并拆分多问，联合处理情绪与问题，重点检验低频/隐含求助漏检。
- 为稀疏、延迟和指代不明弹幕选择课程证据，输出可核对的关联与不确定状态。
- 以逐条证据和教师行动为中心生成复盘报告，验证发现正确性、耗时与实际行动。

“用了LoRA”“接了Agent”“调用多个开源模型”只是技术实现，单独不构成已证明的创新。相同底座、相同输入、相近计算预算下的比较才能说明具体机制有无贡献。

## 四、往年全国大创优秀案例

检索以2024年第十七届、2025年第十八届全国大学生创新年会为主。以下为有公开获奖来源的目的性案例选择，不是全部获奖项目的统计调查，不用于推出获奖因果规律。

| 案例与时间 | 来源可支持的事实 | 转化为本项目目标（我们的推断） |
|---|---|---|
| 中国石油大学（华东）“基于人工智能的类药分子筛选平台”，2024 | 高校官方报道其国家级大创项目获第十七届年会“我最喜爱的项目”；包含模型方法改进及平台实现 [U17] | 中期形成具体方法对照和真实系统，不能只展示模型接口 |
| 南京大学软件学院“对事件驱动的智能家居系统模型的模糊测试方法”，2025 | 南京大学报道该论文获第十八届年会“优秀论文” [U18] | 围绕一个明确软件研究问题形成论文证据，而非不断扩功能 |
| 清华大学“湍流中细长颗粒的碰撞理论模型”，2025 | 学校报道项目成果论文获年会“优秀学术论文”，核心为理论模型研究 [U19] | 基础研究深度也可形成优秀成果，商业化不是唯一方向 |
| 东北大学“基于机器视觉的小青菜田间管理机”，2025年会、2026报道 | 东北大学在中国大学生在线校园号报道其获“我最喜爱的项目”“最佳创意项目”，并介绍长期现场研发 [U20] | 中后期做持续教师试用和真实需求验证，不能用一次演示代替应用证据 |
| 南京大学“瑾瑜虚像-面向药动/药效推演的虚拟人体大模型”，2025 | 学校报道获“最佳创业项目”并作闭幕式路演 [U18] | 创业路线单独评估，需要应用条件；不将它设为创新训练的统一门槛 |

案例新闻中的效益、领先性等属于项目或学校报道，未取得独立实验材料，本研究不将宣传性效果数字作为已经复核的事实，也不照抄其论文/专利数量为自己的指标。未确认获奖的年会展示项目不混入获奖表，省级创新年会及其他竞赛不冒称全国大创年会。

年会设置学术论文、改革成果展示和创业推介等不同交流路径。[U18–19、U21] 大连理工本批次的级别确定依据本校实际程序，已核验为2027年3月按中期检查确定国家级、省级。[U22] 因而应区分：
1. 国家级项目认定：按学校和主管部门要求准备中期证据。
2. 全国年会优秀成果：结题阶段可争取的更高质量展示目标，需届时推荐资格。
3. 商业推广：只有使用需求、权限与运维成熟才推进的应用路线。

本项目适合优先“研究论文 + 改革成果展示”的准备路径。论文主线、运行系统、教师证据和团队独立完成记录比预先承诺大量论文专利更有意义；这是结合案例作出的设计判断，不是官方排名公式。

## 六、仍不足以闭环的证据

- 尚无专门模型在本任务上的独立结果；“前沿”表示近期方法候选，不表示已优于基线。
- 首页分类是基于多条教育/NLP依据形成的操作化方案，尚需教师和标注一致性验证，并非官方颁布的六类统一标准。
- 自然弹幕无法单独证明学生掌握、教师因果作用或学习提升，计划中的教师试用也不能替代学习结果实验。
- 数据许可、三课素材、云节点和FrameScope源码未落实；纸面计划不能解除这些依赖。
- 年会案例只是可借鉴路径，不能保证国家级认定、年会入选、论文录用或专利授权。
