# 申报材料使用说明

申报书将研究依据和设计结论写入相应学术部分，操作指南、检索记录及待完成项单独保存。

| 材料 | 申报用途 |
|---|---|
| 前沿相关研究综述及核心论文 | 背景、研究现状与方法比较 |
| 教学反馈判定细则及标注规范 | 六类反馈、五个教学方面和证据要求 |
| 核心创新方案及实验与验证 | 问题覆盖、局部取证和教师研究 |
| B站数据路线及授权材料 | 数据取得、权限和风险处理 |
| 工程研究、数据契约及FrameScope接入说明 | 技术路线与可行性 |
| 阶段计划及学校通知核验 | 工作安排、预期成果和申报程序 |

研究技术路线.mmd与阶段安排.mmd为两张图的可编辑源文件；同名SVG用于图形编辑，PNG用于Word嵌入。图示表达拟实施路线，不代表已完成运行。
生成申报书.py读取上级目录的正文Markdown及本目录PNG，生成同名Word。使用已配置的Python与python-docx运行；每次生成后重新检查文档排版。
