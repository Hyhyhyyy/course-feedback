# 立项前实施与验收

## 完成定义

真实闭环：对有权处理的真实课程文件和真实弹幕，实际调用已部署模型，生成同源图表、问题清单和证据报告，保存教师复核与行动，失败可定位、再次运行可追踪。本地静态示意、预写分析或假模型接口不能计入真实闭环通过。

## 依赖顺序与四人分工

| 阶段 | 工作与建议责任 | 产物 | 通过条件 |
|---|---|---|---|
| G0 输入落实 | 组员A与导师处理数据/伦理；组员B准备媒体 | 一份真实授权素材包及用途记录 | 可读媒体、带播放毫秒的真实弹幕、当前处理权限 |
| G1 服务冒烟 | 组员C部署主模型，B部署ASR/OCR | 各服务真实输入输出与环境清单 | 模型实际加载；中文结构输出；音频转写和画面识别可查 |
| G2 垂直贯通 | C实现流水线，D实现报告；A抽核 | 一条完整真实课程报告 | 每个必需阶段成功、真实证据可点开、动作能保存 |
| G3 三种课型 | B/C批处理，A/D复核 | 三课运行清单、错误与资源记录 | 所有计划输入输出均有真实样例，无静默丢数据 |
| G4 研究准备 | A冻结标注与测试，四人共同复现 | 独立短片段测试与基线记录 | 未用测试调参；能解释错误及主张边界 |

上述责任是分工建议，不假定已指定成员。按依赖验收，不承诺在未知素材和环境条件下固定天数交付。立项材料如先截止，写明实际达到哪个G阶段。

## 每项计划输出的验收

| 输出 | 必须看到的真实表现 |
|---|---|
| 链接输入 | 来源登记匹配素材；连接器无权限时显示待导入，不绕过限制 |
| 弹幕分布图 | 从原记录程序计数，末窗按实际时长，缺失区间独立显示 |
| 知识点和时间分段 | 边界有转录/画面来源，教师可改，知识点数量定义明确 |
| 六类反馈 | 各类点击到全部记录；重叠不相加当人数；积极内容可查 |
| 全部已识别问题 | 一条多问有多个question_unit；单次/笼统/待核可达 |
| 问题概述与词云 | 每主题可回到全部单元；否定和条件不被合并；频数精确表一致 |
| 内容总结 | 只总结授课材料，段段能定位，不混成学生反馈 |
| 阶段性反馈分析 | 说明某播放区间出现的表达，不冒充同一学生的学习轨迹 |
| 音视频辅助解释 | 原声、转录、帧能定位；推测标明，反面证据可查 |
| 证据报告 | 所有ID有效；人工抽核语义支持；模型输出中无依据项被拦截 |
| 教师行动 | 保留/改进/不改/待核可保存，刷新/重启后仍在 |
| 复现与导出 | report.json与HTML同源；记录模型/配置/hash；清理派生结果后能再生成 |
| 失败恢复 | ASR、模型超时、文件坏损可复现；恢复不重复计数，不把失败写成零 |
| 安全边界 | 恶意弹幕当作文本显示；无HTML执行、外部数据越权、跨课程引用 |

确定性工程检查要求全部通过，包括引用ID有效性、已识别问题可达和计数一致。模型语义准确率不虚构统一达标线：试点后与导师按任务损失设阈值，独立测并报告不确定性。部分降级输出不得标“全闭环通过”。

## 真实运行记录格式

每次验收保存run_id、输入hash、数据用途编号、代码commit、各模型revision、镜像摘要、提示hash、配置、开始结束时间、峰值显存、重试和失败数、各输出路径、人工核查结论。只维护当前产品文件；实验所需原始结果与配置是有效证据，不因“不留历史版本”而销毁有效研究记录。超出保留期限或失去许可的数据按规则处置。

教师闭环记录action_id、关联claim_id、决定、具体行动、教师说明、后续验证方式与状态。没有采纳是允许的结果，不能自动替教师勾选“已改进”。

## 申报表述边界

G1之前：已完成需求、证据体系、原型与技术选型研究。
G2通过后：已在一条授权真实课程上实现端到端原型，附已知错误。
G3通过后：已完成三种课型可行性运行；准确性及教师效用按实际评测说明。
不得将以上阶段写成已完成大规模推广、已证明学习增益或必获国家级。
