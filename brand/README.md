# 课镜基础视觉资源

面向高校师生的教学平台：可信、清晰、亲切。此包为首轮基础设计，不替代学校身份或认证标志。

## 文件

- `readme-banner.png`：仓库首页品牌横幅。

- `kejing-logo.png`：图形与“课镜”字标横向组合，1774×887，真实透明背景。
- `xiaojing-welcome.png`：“小镜”书页精灵欢迎主形象，1246×1262，真实透明背景。
- `kejing-symbol.svg`：独立设计的纯色几何图标，可缩放，用于小尺寸和界面入口；是同概念简化图形，与生成图的轮廓并非逐像素一致。
- `kejing-symbol-mono.svg`：深蓝单色图标，适合文档、单色印刷。
- `kejing-symbol-white.svg`：白色反白图标，用于深色背景。
- `palette.json`：基础色值。
- `preview.html`：本地资源总览，浏览器打开即可。

## 使用规则

正式报告与合作材料以Logo为主，小镜用于欢迎、功能引导和日常交流。小镜不作为评分裁判、认证标识或教学效果证明。

Logo四周至少保留相当于字标高度四分之一的空白；保持原始比例，勿拉伸、添加发光或叠加复杂背景。横向PNG建议显示宽度不低于180像素，小尺寸优先使用SVG图标。反白图标置于学术蓝背景。

配色：学术蓝 #244A70；青绿 #39877E；暖白 #F6F4EE；琥珀黄 #D9AA52。生成PNG有轻微色彩层次，精确纯色应用使用SVG和palette.json。

图形与字标PNG、吉祥物由AI辅助生成；SVG为独立编写的几何图形。中文字标当前是图像，尚未制作字体轮廓矢量版。生成过程不等于已经完成商标检索或校方品牌授权。已接入平台首页、教学工作台、独立HTML报告及仓库README；
