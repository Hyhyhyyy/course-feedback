# 自有课程平台的运行说明

主入口 `/` 提供注册登录、课程广场、教师上传与发布、视频播放和弹幕互动。`/workspace?course=课程编号` 为教师分析入口。首个注册账号初始化为教师，其后为学习者；课程不分班级，发布后向注册用户开放，草稿仅上传教师可见。

后端 `teaching_platform.py` 使用SQLite保存用户、会话、课程及弹幕；密码以PBKDF2加盐摘要保存，会话Cookie为HttpOnly与SameSite=Strict。媒体通过带权限检查的Range请求播放，教师只可管理本人课程。当前本机HTTP试验不具备公网部署的完整条件。

上传支持H.264视频与AAC音轨的MP4、上限512MB，流式写盘并校验内容，生成草稿。弹幕保存播放位置，2秒发送间隔、最长300字，前端使用文本节点避免原文当HTML执行。当前列表上限20000条，真实大规模使用需分页和流式订阅升级。

模型分析由教师触发，先冻结已同意且未撤回的弹幕；未同意的记录只参与课堂互动。快照生成统一XML/JSON和来源映射，复用反馈分析器。新弹幕不修改分析输入。撤回会暂停旧报告访问，重新分析排除撤回内容；研究缓存的正式保留及删除流程待完善。

平台课程支持本地推理；远程分析须教师确认课程材料处理范围，并只纳入学生另行同意当前服务地址的弹幕。地址变化后旧同意不用于新地址；未同意仍可参与互动。真实平台材料的远程全链路尚待验证。新音视频模块见 course-av.md。

第三方平台代码继续保留，环境变量 `COURSE_EXTERNAL_ENABLED=1` 才启用教师扩展入口；仅用于完成合作范围确认后的测试，默认关闭。不会自动迁移旧视频到平台。

实际验证：55项单元测试通过，隔离HTTP完整流程使用自制15.42秒课程完成本地报告，用时35.162秒。浏览器已核对教师课程入口、播放器画面和播放时间推进至00:15。平台账号和测试数据库未上传。申报Word共8页，完成逐页版式检查。
