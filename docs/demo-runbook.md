# 当前立项Demo复现说明

## 启动与输入

API常用方式在源码目录运行 `powershell -File ./start-workbench.ps1`，填写方式见[API说明](api-setup.md)。离线方式运行 `powershell -File ./start-local-demo.ps1`，打开 `http://127.0.0.1:8766`。启动脚本使用已下载的本地权重，不自动向外部模型发送数据。页面显示“已连接本地Qwen3.5”后，可以输入B站链接，按页面提示完成官方扫码登录，再点击“获取数据”。获取成功的提示以实际保存的元信息、弹幕快照和已校验视频为依据。

也可从已获取课程中选择记录，复用素材。教师大纲支持DOCX、TXT和MD或粘贴文本，先保存大纲再生成报告。当前默认选择“课镜音视频复盘”；“弹幕反馈分析”仅处理文本，不生成视频主题概述。

## 运行与输出

点击“生成反馈报告”后，后台依次完成整课转写与取帧、逐原文模型分类、疑问补查、时间窗主题概述、全部已识别问题概述和词云、代表反馈综合复盘及引用校验。前端显示当前处理阶段及原文解析进度。相同原文复用分类，原始弹幕编号和播放时间仍分别保留。

结果为标注前的模型初步分析，教师可以从类别、问题或主题词点击进入单条弹幕，并定位视频。综合结论引用的转写、画面、主题与大纲编号可回查。需要区分“模型未完成分类”和“模型判为语义不明”，前者在报告提供单独待处理入口。没有教师大纲时不生成大纲对应。

报告可导出HTML和JSON；教师确认、排除及文字改进记录分别保存。当前工作台仅在本机提供服务。若服务重启，本地B站登录会话可能需要重新扫码；已保存素材不需要重新取得。

## 路径与核验

- 当前课程输入：`outputs/jobs/<课程任务编号>/assets/`。
- 运行状态：`analysis/state.json`。
- 转写与画面：`analysis/media/`。
- 模型调用证据：`analysis/model-cache/`。
- 当前报告与教师记录：`analysis/report.json`、`analysis/review.json`。
- 模型配置：`data/local-model.json`；权重：`data/models/qwen35-4b/`。

执行 `.venv/Scripts/python.exe -m unittest discover -s tests -q` 检查输入、引用和状态保护。模型权重来源、散列、运行参数和处理限制见[本地模型部署说明](local-model-deployment.md)，完整逐步图见[Demo调用链](demo-flow.md)。项目根目录07_实际试验保存当前真实课程试验报告。

`src/run_demo.py`和`src/oneclick.py`保留早期命令行研究接口；它们不等同于当前工作台的本地模型管线。旧合成测试与失败记录是来源追踪材料，不作为当前真实课程成功运行的证明。
