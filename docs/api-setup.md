# API 接入、实时模型与用量说明

## 填写顺序

打开课镜“模型连接设置”，选择厂商，核对官方接口地址，填写 Key，点击“从官方接口刷新模型”（已填写的新 Key 会先自动保存），在“可用模型下拉列表”选择返回项，选择后自动应用，或根据官方文档填写确切模型 ID，点击“应用所选模型”。最后点击“验证 Key 与文本调用（少量计费）”。该测试只发送一条合成 JSON 指令，不发送课程材料。

文本测试成功后，选择“大模型 API”作为运行方式，再点击生成报告。建议先保留前五分钟、100条抽样。音视频流程还要求所选模型支持图片输入；文本探测成功不能代替视觉及完整报告测试。

Key 仅保留在后端内存，不写入浏览器存储、源码或报告，清除按钮或重启后端均会移除。更改厂商后需要重新保存连接。当前配置不具备多用户账户隔离，服务保持本机监听。

## 官方模型参考

下表为2026年9月14日核验的官方文档参考，并非全部可选模型，也不是本项目效果排名。页面不将这些名称当作永远有效的列表；实际候选由 Key 对应的官方接口刷新，随后用所选模型进行调用验证。

| 厂商 | 官方文档中的相关模型示例 | 本项目拟用位置 |
|---|---|---|
| 阿里云百炼 | qwen3.5-plus、qwen3-max | 前者为图文候选；按具体模型能力选择分类、讲解与综合任务 |
| DeepSeek | deepseek-flash、deepseek-v4-pro | 弹幕与报告文本候选；视觉模型及接口兼容性另行核验 |
| Kimi | kimi-k3、kimi-k2.6 | 图文理解与长材料综合候选 |
| 智谱 | GLM-5.3、GLM-5.3-Flash、GLM-4.6V | 按文本或视觉能力选择，不将图像生成模型用于理解 |
| 硅基流动 | 托管 Qwen、DeepSeek 等系列，具体 ID 以刷新结果为准 | 比较不同开源模型托管服务 |

百炼模型示例及查询方法见[Qwen3.5-Plus官方说明](https://help.aliyun.com/en/model-studio/qwen3-5-plus)和[官方模型查询接口](https://help.aliyun.com/zh/model-studio/list-models)。DeepSeek 示例来自[官方模型列表接口](https://api-docs.deepseek.com/api/list-models/)。Kimi 参考[官方模型表](https://platform.kimi.ai/docs/models)，该页同时说明 kimi-k2.5 与 moonshot-v1 系列已于2026年8月31日退役，因此不预置为当前推荐项。智谱参考[官方模型概览](https://docs.bigmodel.cn/cn/guide/start/model-overview)。硅基流动参考[官方模型查询](https://api-docs.siliconflow.cn/docs/api/models-get)。

百炼使用其专用 `/api/v1/models` 接口并按页获取，其他兼容服务尝试 `/models`。列表请求失败时显示具体状态并保留官方文档手动入口，不用过期硬编码名单伪装刷新成功。不同厂商的列表可能只代表服务目录，不能推断 Key 已获全部模型调用权限。

## 状态与计数的含义

“已保存”只表示本次后端取得配置；“模型列表请求成功”表示目录接口已返回；“Key 与所选模型文本调用已验证”表示该模型实际返回预期 JSON。认证拒绝、权限不足、限流、接口不存在、连接超时与输出结构不兼容分别显示，不把所有错误都归为 Key 无效。

当前连接的调用次数及输入、输出 Token 数来自服务实际返回的 `usage`，包括文本探测和课镜分析。未返回用量的请求单独计数，缓存命中不会重复计入。这些数值不包含其他应用的调用；重启或重新保存连接后开始新的计数，不代表账户总用量或账单金额。

DeepSeek 余额读取[官方 `/user/balance`](https://api-docs.deepseek.com/api/get-user-balance/)，硅基流动读取[官方用户信息接口](https://siliconflow.readme.io/reference/user-info)中的余额字段，只向前端返回所需余额，不展示其余账户资料。其他服务显示“当前厂商未接入余额接口”，引导查看官方控制台。当前不根据 Token 数自行估算余额或声称剩余配额。

## 当前验证边界

本次没有真实厂商 Key，未声称已通过任何远程厂商实测。接口失败、密钥不回传、列表与推理状态区分、百炼分页和用量计数已通过模拟响应测试。真实 Key 由用户在前端填写后验证。校园服务器按用户要求保持【待真实接入测试】，不执行网络试用。专用标注训练权重尚未训练。

发送远程模型前，程序再次遮盖电话、邮箱及“我……实名”式自报身份，保留证据编号与其余问题文字。该处理未覆盖任意姓名、学校或画面内身份信息，完整匿名化仍需材料复核；本次未向远程服务发送真实课程。
