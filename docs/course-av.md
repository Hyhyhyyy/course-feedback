# 课镜独立音视频分析模块

入口为 `src/course_av.py`，由 `workbench.run_analysis` 调用。输入平台课程MP4、所选截止时间和本地语音模型，输出 `transcript.json`、`frames.json`、`windows.json` 及处理日志。该模块独立围绕课程与弹幕的证据关联实现。

首先校验音视频并限制实际处理范围，按180秒语音块转写，相邻块保留1秒上下文并按句段中点归属，缓存记录视频和模型权重哈希。转写保留起止时间、文字及识别分数；识别分数只作复核线索，不等于数学内容正确率。

每5秒解码一个画面，以缩小后的灰度差异寻找候选变化，最短片段30秒、最长180秒。每个候选片段再解码一张代表画面，以实际帧PTS保存播放时间。这样避免只按固定五分钟生成全部概述，但画面变化仍不能证明知识点切换；持续书写、人物运动与静态板书均可能造成误分或漏分。

本地视觉语言模型结合候选片段转写与画面生成讲解概述，程序检查引用编号存在。报告继续保存原文与媒体证据，禁止编造不清楚的公式。后续以人工标注的教学步骤和知识点边界比较固定窗、画面候选及语义辅助方法，并增加公式专项核验，不能把当前启发式规则称作完成科学准确的分段。

平台与音视频模块使用自制合成课程做工程验证，结果见 platform-validation.json。真实教师材料和学生互动仍需独立试验。
