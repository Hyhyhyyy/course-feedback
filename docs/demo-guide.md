# 课镜本地演示与完成边界

更新：2026年9月16日。

## 试用入口

平台：http://127.0.0.1:8766/ 。只允许本机访问。教师和学生演示账号保存在本机 `data/demo-access.json`，凭据不进入仓库。已登录的教师可直接进入标题带“模拟演示”的课程。

1. 教师进入课程，播放视频，点击“复盘本课”。
2. 打开模型设置，选择“离线本地分析”，确认状态正常。已有报告可以直接阅读，无需重新等待推理。
3. 查看六类反馈、问题概述、词云、积极表达、讲解候选片段、转写、画面及大纲对应。点击依据可查看单条原文与时间位置。
4. 在教师复核区保存记录，导出HTML或JSON。
5. 返回平台并退出，使用学生账号登录，播放、发送弹幕。是否用于分析由每条反馈的选择决定；撤回会使既有报告暂停访问，需要教师重新生成。
6. 教师也可上传自己有权使用的H.264/AAC MP4（最大512MB），发布后重复完整流程。

## 实测输入与输出

自制视频15.42秒，100条程序构造反馈。实际调用本机Qwen3.5-4B图文模型及Whisper tiny，首次完整分析462.825秒。产生100条分类、53个问题单元、53个问题组、52个词云条目、4段转写、1张画面、1个讲解候选片段。教学大纲通过真实导入接口加入后重新生成对应分析；缓存复用后最终运行62.9秒，大纲对应均包含大纲原文及讲解或反馈引用。

这是工程演示，不是100名学生或自然课堂实验。重复主题使用不同测试编号，因此问题组数量较多，不应作为聚类质量指标。Whisper tiny在“函数”“可导”等词上出现误识别，转写保留草稿状态。分类与建议同样需要人工检查。

发现模型从提问推断“掌握不足”后，增加了保守措辞筛查，屏蔽命中规则的综合表述并公开拦截数量；模型原始响应仍在本机缓存追溯。此筛查不能替代证据支持程度的人工评价。

## 本次补齐

- 启动脚本改用无需登录的健康检查，避免误判已运行的平台。
- 分析期间仍可撤回反馈；发布报告前检查撤回标记，阻止受影响结果发布。
- 分析期间禁止修改大纲，防止输入漂移。
- 短视频显示秒级范围，修复分块数、平台素材进度及空分P显示。
- 记住主动选择的推理模式，不保存API Key到浏览器。
- 模拟数据标识贯穿分析和导出；报告不把模拟材料称作自然样本。
- 配置完成本机教师、学生演示账号，验证权限、视频范围播放、反馈发送和撤回、复核与导出。

单元测试58项；20项HTTP功能检查和5项互动、撤回及输入锁定检查通过。浏览器已核验本地模型正常状态、报告展示、单条依据弹窗和视频时间定位。当前HTTP验证数据在 `outputs/demo-http-validation.json` 和 `outputs/demo-interaction-validation.json`；完成报告保存在对应课程的 `outputs/jobs/<id>/analysis/`。测试脚本 `scripts/validate_demo.py` 会写入演示复核记录，只用于此演示账号和课程。

## 重启与复现

本机已安装依赖、权重和运行器，运行根目录 `start-local-demo.ps1` 可启动平台和本地模型。停止服务后重新运行不会清空课程。模型首次加载需要等待，页面中检查本地模式状态。

`prepare_demo.py` 创建演示账号和模拟课程，不覆盖已有同名账号。它依赖本机自制样例 `outputs/platform-smoke/lesson.mp4`；该媒体未随Git提交，新克隆仓库应提供自己的授权样例。`data/demo-access.json` 已存在时脚本不会重复创建。
