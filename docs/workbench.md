# 课镜工作台当前实现

课镜现有获取数据、选择推理方式、100条抽样试用、音视频辅助复盘、大纲导入、逐条依据回查、教师复核与 HTML / JSON 导出。

当前真实试验素材来自 BV1Y2DGYoEEw 第一分P：54分钟课程、7200条取得时可用的弹幕。完整媒体预处理得到1506段转写和28张画面。最终验收仅分析前五分钟的100条去重等间隔抽样弹幕，配合153段范围内转写与3张画面，产生23个问题单元、25个主题词和1个主题窗。引用与数量校验通过；玩梗误判、字面误读和转写错误仍存在，不报告未经人工验证的准确率。
